# GS-DIGM-6074-project-gzapper
Electro Magnetic multi looper with saturation

The goal is to create a noise looper using an Sonorus Objects Electro Magnetic mic as RF noise source into a quad looper with saturation and possible loop length adjustments on the fly.
The hardware will either be an Ableton Move, building in RNBO or with a Daisy, likely buying a prefab Daisy board (seed desktop unit, though pricey).

Issues, the EM mic as looper base will work better with triggered recording/overdubbing. An initial loop pass would likely want a rhythmic gate.
Ableton Move uses pads which aren't as nice as switches and visually won't be as interesting as a homemade rig.

Using the daisy desktop means making a case, which I would prefer to do out of wood for aesthetic reasons. But its expensive.

Balancing tanh saturation and feedback to create long form noise/industrial loop performances means balancing feedback and saturation on minute levels.

Gen looper ideas are being sourced from RNBO patches along with Greg Taylor and Jeff Kaiser's building loopers book.
